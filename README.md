# WanderLust - Airbnb Style Rental Listing Platform

WanderLust is a full-stack web application inspired by Airbnb where users can browse, create, edit, and delete rental property listings.

## Features
- User Authentication (Signup/Login/Logout) using Passport.js
- Create, Read, Update, Delete (CRUD) operations for listings
- Upload property images using Multer + Cloudinary
- Responsive card-based UI using Bootstrap
- Property detail pages
- Session management using express-session
- Flash messages for user feedback
- Cloud database integration using MongoDB Atlas
- Deployed on Render

## RESTful Routes Implemented
- GET → Fetch listings
- POST → Create listings
- PUT → Update listings
- DELETE → Remove listings
